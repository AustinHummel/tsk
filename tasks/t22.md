# 2.2 Pending merge in HEAD and a git merge driver

`t22` · status **complete**

Path: [2 Merge divergent stores (0.3)](t20.md)

`.tasks/HEAD` may carry a second line `merge <hash>`; any command then performs the merge first (writes), or warns (reads). A git merge driver (`tsk merge-driver`, installed by `tsk git-setup`) resolves a HEAD conflict by writing that pending line, so `git pull` never blocks; without the driver, `tsk merge` reads git's conflict markers from HEAD.
