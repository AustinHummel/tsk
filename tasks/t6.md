# 1.5 Link tasks and markdown both ways

`t6` · status **complete**

Path: [1 Make tsk fit a hierarchical agent org (0.2)](t1.md)

A task points at the vault nodes it serves; a rendered markdown mirror lets a vault note link to a task and lets Obsidian browse the tree.

## Breakdown

Task to markdown is a stored pointer (1); markdown to task needs a page to link to (2) and a way to find who linked (3). Fields show on the rendered page, so that requirement goes to 2.
