# 5.1 Claim before advancing HEAD

`t49` · status **complete**

Path: [5 No write is ever lost (0.4.2)](t48.md)

Advancing HEAD from event p first claims p with an atomic create of `.tasks/claims/<p>`; a second writer on the same parent is refused with "the store moved; nothing was written; run it again" (exit 3). Correctness no longer depends on the lock at all. A reset releases its target's claim, since committing there again is legitimate.
