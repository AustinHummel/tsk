# 5.2 Break only the lock that was judged stale

`t50` · status **complete**

Path: [5 No write is ever lost (0.4.2)](t48.md)

Locks carry a token; breaking takes the file aside, checks the token matches the one judged stale, and hands back any newer lock it displaced. A displaced lock's owner sees its token gone, and its drop no longer deletes a successor's lock.
